## 3. Как устроены координаты в порте (важно, иначе съедет)

`Spec { x, y, size }` — не «проценты экрана»:

```rust
// Gui::anchor(fx, fy)
let (rx, ry) = (fx * 560.0, fy * 270.0);          // эталонная сетка 560 x 270
let x = if (rx - 280.0).abs() <= 110.0 { w/2.0 + rx - 280.0 }   // от центра
        else if rx < 280.0 { rx }                                // от левого края
        else { w - (560.0 - rx) };                               // от правого края
let y = if ry > 135.0 { h - (270.0 - ry) } else { ry };           // от низа / от верха
```

* `size` — **половина** размера контрола в единицах этой сетки (рисуется `c ± r`).
* `w`, `h` здесь — размер GUI в GUI-единицах, а не в пикселях экрана. Экранный пиксель = GUI-единица ×
  `s`, где `s = screen_px_width / gui_width`.

**Сначала узнай `s` для своего устройства.** Способ без догадок: порт рисует хотбар шириной 182
GUI-единицы (`hotbar_x` и константа 182). Сделай скриншот игры, измерь ширину хотбара в px:
`s = hotbar_px / 182`. Для 3200×2136 и GUI-ширины 560 `s = 5.714`.

Пересчёт измеренного контрола (центр `cx, cy`, полуразмер `half`, экран `W×H`) в `Spec`:

```
L = cx/s ; R = (W-cx)/s ; T = cy/s ; B = (H-cy)/s
x: |cx - W/2|/s <= 110  -> fx = (280 + (cx - W/2)/s) / 560
   иначе cx < W/2       -> fx = L / 560
   иначе                -> fx = (560 - R) / 560
y: cy/s > 135           -> fy = (270 - B) / 270
   иначе                -> fy = T / 270
size = half / s                          (половина!)
```

## 5. Что именно поменять в `bedrock()`

1. Подставь семь `Spec` из таблицы (`at(fx*560, fy*270, size)` уже делает нормировку — просто передай
   `fx*560`, `fy*270`, `size`).
2. **Джойстик статичный и всегда видимый** (на скриншоте база нарисована без касания):
   `stick_floating: false`, `stick_always: true`. Плавающий режим остаётся опцией для игрока.
3. **Кнопки полёта `Id::FlyUp/FlyDown` спрячь** (`visible: false`): в Bedrock в полёте те же места
   занимают «прыжок» и «присед», а в порте прыжок уже поднимает, присед опускает
   (`touch_press`: `Jump -> Button::South`, `Sneak -> Button::RightStick`).
4. **Спрячь лишнее для Bedrock-пресета**: `Id::Attack`, `Id::Use`, `Id::Mount`, `Id::Action`
   (`visible: false`) — в измеренном HUD Bedrock их нет (кнопка действия у Bedrock опциональна и по
   умолчанию выключена). `Id::AimToggle`, `Id::Drop`, `Id::Inventory` и F-клавиши оставь как есть.
5. `Id::Edit` (шестерёнка редактора) — это фича порта, не Bedrock. Оставь маленькой в правом верхнем
   углу и помечай в отчёте как осознанное отклонение.
6. Поменялись дефолты → **подними версию файла раскладки**: `LAYOUT_FILE` с `touch_layout_v4.json`
   на `touch_layout_v5.json`, иначе у игроков останется старый сохранённый файл.
7. `dpad()` и `standard()` не трогай.

## 6. Как проверить

```sh
# 1) типы (mod touch НЕ под cfg(android), поэтому хост-проверки достаточно)
cargo check -p horizon-client --lib

# 2) применить патч в дереве «порт + все патчи репозитория»
git apply --check android-patches/0029-*.patch     # и потом git apply

# 3) собрать APK как CI
./packaging/android/build_apk.sh
```

На устройстве:

1. Установить APK, зайти в мир, сделать скриншот **тем же разрешением 3200×2136**.
2. Прогнать `tools/01_components.py` и `tools/03_refine.py` (поменять в них путь к картинке) — они дают
   прямоугольники контролов. Сравнить с `geometry.json`.
3. Критерий приёмки: центры совпадают в пределах **±3 px**, размеры ±4 px, ничего не налезает на хотбар,
   редактор раскладки по-прежнему двигает/сохраняет контролы.

## 7. Грабли, на которые уже наступали

* `Game::motion` — это `MotionResources`, а не состояние игрока. Полёт: `self.player.as_ref().is_some_and(|p| p.flying)`.
* Добавишь вариант `Id` — обнови **три** места: `IDS`, `icon()` и `touch_press()` (там нет `_`).
* `Gui::hit` принимает 4-й аргумент `flying: bool` — не забудь про все вызовы.
* `size` — половина размера; если подставишь полный, контролы будут вдвое больше.
* Не «улучшай» геометрию на глаз: числа из `geometry.json` получены с точностью ±2 px.
* Раскладка на скриншоте — **текущая у игрока**; если он когда-то двигал контролы, это не заводская.
  Не сбрасывай чужие настройки (Reset меняет данные игрока).
* Иконки зависят от состояния (под водой — «всплыть/погрузиться», в полёте — стрелки), но **рамки и
  позиции те же**; ориентируйся на рамки, не на иконки.
