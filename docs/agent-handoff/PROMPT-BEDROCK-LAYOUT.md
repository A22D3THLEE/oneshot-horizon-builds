## Правила пересчёта (обязательно прочитай, иначе всё съедет)

`Spec` в порте — не проценты экрана:

```rust
// Gui::anchor(fx, fy)
let (rx, ry) = (fx * 560.0, fy * 270.0);            // эталонная сетка 560x270
let x = if (rx - 280.0).abs() <= 110.0 { w/2.0 + rx - 280.0 }  // от центра
        else if rx < 280.0 { rx }                              // от левого края
        else { w - (560.0 - rx) };                             // от правого
let y = if ry > 135.0 { h - (270.0 - ry) } else { ry };         // от низа / от верха
```

* `size` — **половина** размера (рисуется `c ± r`), в единицах сетки 560×270.
* Экранный пиксель = GUI-единица × `s`. Сначала определи `s` на своём устройстве:
  порт рисует хотбар шириной **182 GUI-единицы**, значит `s = ширина_хотбара_px / 182`;
  для 3200×2136 при GUI-ширине 560 `s = 5.714`.

Пересчёт (центр `cx,cy`, полуразмер `half`, экран `W×H`):

```
L=cx/s ; R=(W-cx)/s ; T=cy/s ; B=(H-cy)/s
x: |cx-W/2|/s <= 110 -> fx=(280+(cx-W/2)/s)/560 ; cx<W/2 -> fx=L/560 ; иначе fx=(560-R)/560
y: cy/s > 135        -> fy=(270-B)/270        ; иначе fy=T/270
size = half/s
```

Значения в таблице уже посчитаны при `s=5.714`. Если на устройстве `s` другой — пересчитай по формулам
из `geometry.json` (там px-прямоугольники).

## Что именно сделать

1. Подставь семь `Spec` в `TouchLayout::bedrock()`.
2. Джойстик **статичный и всегда видимый**: `stick_floating: false`, `stick_always: true`
   (на скриншоте база нарисована без касания). Плавающий режим оставь опцией игрока.
3. `Id::FlyUp` / `Id::FlyDown` спрячь (`visible: false`): в Bedrock в полёте те же места занимают
   прыжок и присед, а в порте `Jump -> Button::South` (вверх), `Sneak -> Button::RightStick` (вниз).
4. Спрячь для Bedrock-пресета `Id::Attack`, `Id::Use`, `Id::Mount`, `Id::Action` — в измеренном HUD
   Bedrock их нет. `AimToggle`, `Drop`, `Inventory`, F-клавиши оставь как есть.
5. `Id::Edit` (шестерёнка редактора) — фича порта; оставь маленькой в правом верхнем углу и укажи это
   в отчёте как осознанное отклонение.
6. Поменялись дефолты → подними `LAYOUT_FILE` с `touch_layout_v4.json` на `touch_layout_v5.json`,
   иначе у игроков останется старый сохранённый файл.
7. `dpad()` и `standard()` не трогай. Ничего, кроме `touch.rs` (и версии файла раскладки), не меняй.

## Грабли

* `Game::motion` — это `MotionResources`, не состояние игрока; полёт:
  `self.player.as_ref().is_some_and(|p| p.flying)`.
* Добавишь вариант `Id` — обнови `IDS`, `icon()` и `touch_press()` (в последних двух нет `_`).
* `Gui::hit` принимает 4-й аргумент `flying: bool`.
* `size` — половина; полный размер даст вдвое большие контролы.
* Иконки зависят от состояния (под водой «всплыть/погрузиться», в полёте стрелки), рамки и позиции —
  нет; ориентируйся на рамки.
* Измеренная раскладка — **текущая у игрока** и может быть кастомной. Не сбрасывай его настройки
  (Reset в «Настроить управление» меняет данные игрока).
